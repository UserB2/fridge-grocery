# 오늘의 냉장고

요리를 고르면 장보기 목록을 만들고, 구매 기록을 남겨 냉장고로 이어 주는 한국어 웹앱입니다.

## 사용하기

[웹사이트 열기](https://userb2.github.io/fridge-grocery/)

1. **요리 고르기**에서 한식·양식·중식 30가지 요리 중 원하는 것을 선택합니다. 재료를 검토한 뒤 장보기 목록으로 보냅니다. 공통 재료는 중복해서 담지 않습니다.
2. **장보기**에서 품목을 직접 추가하거나 수량을 수정합니다. 이름·연결된 요리 검색, 식품 분류, 미구매/구매 완료 필터를 조합해 목록을 좁힐 수 있습니다. 필터는 표시만 바꾸며 구매 내역 저장과 합계는 전체 목록의 구매 체크 품목 기준입니다. 구매한 품목을 체크하고, 품목 전체에 지불한 금액을 입력합니다. 예를 들어 우유 2개를 $6에 샀다면 수량은 2, 금액은 6입니다.
3. **구매 내역 저장**에서 구매일·구매처·통화·영수증 총액을 기록합니다. 기록만 저장하거나 구매품을 바로 냉장고에 넣을 수 있습니다.
4. **구매 내역**에서 가격을 나중에 보완하거나 아직 등록하지 않은 구매품을 냉장고로 보냅니다. 등록한 품목은 다시 넣지 않으며 구매 기록은 유지합니다.
5. **내 냉장고**에서 소스/양념·육류·수산물·채소 등 분류와 냉장·냉동·실온 보관 위치를 조합해서 확인합니다.

## 저장과 프로필

로그인하지 않으면 기존처럼 이 브라우저의 프로필과 목록을 사용합니다. 로컬 프로필은 로그인 계정이 아니며 같은 브라우저의 다른 사람이 선택할 수 있습니다. 사이트 데이터를 지우면 로컬 기록이 사라집니다. 로컬 모드는 한 번에 한 탭에서 편집해 주세요.

프로필 메뉴에서 **회원가입**을 선택하면 이메일과 비밀번호로 가입하고 바로 로그인할 수 있습니다. 다른 기기에서는 **이메일로 로그인**을 눌러 가입할 때 쓴 정보를 입력합니다. **Google로 로그인**도 지원하며, 같은 이메일을 사용해도 Google 계정과 이메일 가입 계정은 별개입니다. 가입 인증과 비밀번호 찾기 메일은 보내지 않습니다. 로그인 상태에서는 현재 비밀번호를 입력해 비밀번호를 변경할 수 있습니다.

같은 계정의 주방·냉장고·장보기·구매 기록을 Supabase에 저장합니다. 기존 로컬 프로필은 사용자가 선택해 가져오며 자동 업로드하지 않습니다. 다른 기기와 충돌하면 덮어쓰지 않고 입력 보관 후 최신 기록을 불러오도록 안내합니다. 오프라인에서는 마지막으로 받은 계정 기록을 볼 수 있으나 편집 내용을 대기열에 넣지 않습니다.

프로필 메뉴의 **현재 목록 내보내기**로 냉장고·장보기·구매 내역을 JSON 파일에 보관할 수 있습니다. 계정에서는 이 파일도 가져올 수 있습니다. 로그아웃하면 계정 캐시를 지우고 이 기기의 로컬 프로필로 돌아갑니다. 주방 이름은 계정 안의 분류이며 별도의 로그인 계정이 아닙니다. [개인정보 안내](./privacy.html)

연결 절차는 [무료 계정 설정](./supabase/SETUP.md)을 참고하세요. **Supabase Free + 기존 GitHub Pages**를 사용하며, 결제 수단이나 이메일 발송 서비스·별도 도메인은 필요하지 않습니다. 무료 한도 초과 또는 휴면 시 동기화가 제한될 수 있고 자동 유료 전환은 하지 않습니다. `cloud-config.js`가 비어 있으면 로컬 모드만 동작합니다.

USD와 KRW를 지원하며 통화가 다른 구매 기록을 합산하지 않습니다. 미입력 가격과 0원은 구분합니다. 재료 매칭은 보유 여부 기준으로, 소비기한이 지났거나 수량이 0인 재료는 제외합니다. 실제 상태와 요리에 충분한 양은 직접 확인해 주세요. 레시피는 이 앱을 위해 직접 작성한 간단한 조리 안내입니다.

## 로컬 실행과 확인

설치할 패키지나 빌드 과정은 없습니다. 폴더에서 정적 웹 서버를 실행한 뒤 브라우저로 엽니다. ES 모듈을 사용하므로 파일을 직접 더블클릭하는 대신 웹 서버로 열어야 합니다.

```sh
python3 -m http.server 8765
```

Node.js 22 이상에서 `npm ci` 후 핵심 동작·실제 PostgreSQL 권한·화면 테스트를 실행할 수 있습니다. 패키지는 테스트에만 필요합니다.

```sh
node --test tests/*.test.js
```

GitHub Pages는 `main` 브랜치의 루트를 배포합니다.
