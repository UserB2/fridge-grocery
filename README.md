# 오늘의 냉장고

요리를 고르면 장보기 목록을 만들고, 구매 기록을 남겨 냉장고로 이어 주는 한국어 웹앱입니다.

## 사용하기

[웹사이트 열기](https://userb2.github.io/fridge-grocery/)

1. **요리 고르기**에서 한식·양식·중식 30가지 요리 중 원하는 것을 선택합니다. 재료를 검토한 뒤 장보기 목록으로 보냅니다. 공통 재료는 중복해서 담지 않습니다.
2. **장보기**에서 품목을 직접 추가하거나 수량을 수정합니다. 구매한 품목을 체크하고, 품목 전체에 지불한 금액을 입력합니다. 예를 들어 우유 2개를 $6에 샀다면 수량은 2, 금액은 6입니다.
3. **구매 내역 저장**에서 구매일·구매처·통화·영수증 총액을 기록합니다. 기록만 저장하거나 구매품을 바로 냉장고에 넣을 수 있습니다.
4. **구매 내역**에서 가격을 나중에 보완하거나 아직 등록하지 않은 구매품을 냉장고로 보냅니다. 등록한 품목은 다시 넣지 않으며 구매 기록은 유지합니다.
5. **내 냉장고**에서 소스/양념·육류·수산물·채소 등 분류와 냉장·냉동·실온 보관 위치를 조합해서 확인합니다.

## 저장과 프로필

프로필은 아이디별로 이 브라우저의 목록을 구분하는 기능입니다. 로그인 계정이 아니며 같은 브라우저에서는 다른 프로필을 선택할 수 있습니다. 목록은 `localStorage`에만 저장되고 서버로 전송되지 않습니다. 다른 기기·브라우저로 자동 동기화되지 않으며 브라우저 사이트 데이터를 지우면 기록이 사라집니다. 한 번에 한 탭에서 편집해 주세요.

USD와 KRW를 지원하며 통화가 다른 구매 기록을 합산하지 않습니다. 미입력 가격과 0원은 구분합니다. 재료 매칭은 보유 여부 기준으로, 소비기한이 지났거나 수량이 0인 재료는 제외합니다. 실제 상태와 요리에 충분한 양은 직접 확인해 주세요. 레시피는 이 앱을 위해 직접 작성한 간단한 조리 안내입니다.

## 로컬 실행과 확인

설치할 패키지나 빌드 과정은 없습니다. 폴더에서 정적 웹 서버를 실행한 뒤 브라우저로 엽니다. ES 모듈을 사용하므로 파일을 직접 더블클릭하는 대신 웹 서버로 열어야 합니다.

```sh
python3 -m http.server 8765
```

Node.js 22 이상에서 핵심 동작 테스트를 실행할 수 있습니다.

```sh
node --test tests/*.test.js
```

GitHub Pages는 `main` 브랜치의 루트를 배포합니다.
